# Upstream work

This folder is the working area for changes that Runebender proposes to other projects.
Each organization has a folder, because each has its own contribution rules.
Each planned pull request has one file, which holds the research, the decision, the code record and the text of the pull request.

- [linebender/](linebender/README.md): Xilem, Masonry, Vello, Kurbo and `spline`.

Nothing in this folder is sent upstream as a file.
It is the record that the pull request is made from.
