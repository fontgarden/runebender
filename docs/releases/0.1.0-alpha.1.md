# Runebender 0.1.0-alpha.1

The first downloadable alpha of the native Runebender font editor.
This is experimental software: work on copies of important fonts and keep your sources in version control.

## macOS installation

This release is for Apple Silicon Macs running macOS 12 or later.
Open the DMG, drag Runebender to Applications, eject the image, and launch the installed app.
Use File > Open to open a UFO or Designspace.
Rust and Homebrew are not required for the packaged editor.

## In this alpha

- Start in the normal glyph grid with an untitled font and 324 empty Latin Core glyph slots.
  The first Save asks for a destination folder; launching the editor does not write a font to disk.
- Browse glyphs, draw and edit outlines, work with components, and undo and redo edits.
- Edit UFO and Designspace sources, work with masters, and use the spacing and kerning tools.
- Review drawings with Before/Working comparisons and quick toggling, plus selectable Waterfall and Text proofs.
  Choose project-local reference fonts in a Git-ignored `reference-fonts/` directory, shared with the Virtua proof workflow.
  Agents can request comparison images through MCP when Designbot is installed.
- Use the revised native interface, configurable themes, and application menu bar.
- Build non-destructive workflows with Graph and connect separately installed local AI tools through Chat.
- Check for updates at launch or through Runebender > Check for Updates….
  Installation requires confirmation, and an update restart prompts before unsaved font edits are discarded.

## Known limitations

- This is the first alpha, with incomplete workflows and source-format compatibility limits.
  Verify saved results before using them in production.
- Local AI models, llama-server, Designbot, and other external tools are separate installations.
  They are optional for core outline editing; features that use them require their own setup.
- Finder font-file associations and double-click opening are not advertised in this release.
- Intel Mac and Windows installers are not included.
- Linux users can build from source using the instructions on runebender.org.

Report reproducible issues with your macOS version, the Runebender version, and a small font fixture that you are allowed to share.
Source and issue tracker: https://github.com/fontgarden/runebender.
