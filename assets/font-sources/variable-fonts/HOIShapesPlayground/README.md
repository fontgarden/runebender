# HOI Shapes Playground

Open [HOIShapes.designspace](HOIShapes.designspace) in Runebender, open `box`, and press `I` to edit interpolation.
Drag a line between the masters to bend its path, then use the easing buttons and Progress slider.
You can save your experiments here.

This is the editable test copy of [HOI Shapes](../HOIShapes/README.md), kept beside the other sample fonts.
It starts with the same three masters and straight interpolation paths.
The automated tests use the separate HOIShapes baseline.
